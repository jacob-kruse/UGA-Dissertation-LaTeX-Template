      \subsection{Table Example}
        In this subsection, we are going to give an example of a table and how one will look. There are many ways to make a table and customize them. Here is one example:


      \begin{table}[ht]
        \centering

      \begin{tabular}[c]{|l|c|rc|}
        \hline
        left justified  & centerd  & right justified  & no left border\\
        \hline
        row 1 & fill & in between & the \&s\\
        row 2 & & &\\
        \hline
      \end{tabular}
      \caption{The Caption of the table.}
      \label{table:someTable}
      \end{table}

        The above does not meet PDF accessibility standards, but below is an identical table that does.
      \begin{table}[ht]
        \centering

      \begin{tblr}[c]{
        colspec = {|l|c|rc|},
        width = \textwidth,
        hline{1,2,Z} = {0.7pt}
      }
        left justified  & centerd  & right justified  & no left border\\
        row 1 & fill & in between & the \&s\\
        row 2 & & &\\
      \end{tblr}
      \caption{The Caption of the table.}
      \label{table:someTable2}
      \end{table}

        You can also reference an equation just like a figure and table. There are two different enviornments that are needed. The first is just using the equation enviornment. This is useful when you have one equation to write. As seen here:
          \begin{equation*}
            Y=\beta_{0} + \sum\limits_{i=1}^n \beta_{i}X_{i} + e
          \end{equation*}
        The equation for the general multiple linear regression model is above. This is a good use case for the equation enviornment. \LaTeX  knows to expect math symbols inside the enviornment. What if you need more than one line? What if each line need to align? Thats when the align enviornment comes in handy.       \subsection{Algorithm Examples}
        Algorithms are another common inclusion to documents. Below are two examples of the same algorithm. The first example utilizes the "algorithm" package and is more commonly used. 
          \begin{algorithm}
          \caption{Algorithm Title}
          \label{alg:example}
          \textbf{Inputs}: First input $I_1$, Second input $I_2$
          \newline
          \textbf{Output}: Output $O$
          \begin{algorithmic}[1]
          \State Initialize function $I_1$
          \State Initialize empty list $O$
          \For{$i = 0$ to $I_2$}
              \State Pass current index through function: $o = I_1(i)$
              \State Add current output to running list: $O \gets O \cup o$
          \EndFor
          \State \Return $O$
          \end{algorithmic}
          \end{algorithm}

        The second example illustrates the same algorithm, but is a custom, identical template. Although this is more complicated, the second example meets PDF accessibility standards.

          \begin{flushleft}
          \begin{minipage}{\textwidth}
          \singlespacing
          \refstepcounter{algorithm}
          \tagmcbegin{artifact}
          \hrule height 0.8pt
          \vspace{2pt}
          \tagmcend{}
          \noindent\textbf{Algorithm \thealgorithm} Algorithm Title \\[-9pt]
          \rule{\textwidth}{0.4pt}\\[-4pt]
          \label{alg:exampleforaccessibility}
          \noindent\textbf{Inputs}: First input $I_1$, Second input $I_2$
          \newline
          \noindent\textbf{Output}: Output $O$
          \begin{algorithmic}[1]
          \State Initialize function $I_1$
          \State Initialize empty list $O$
          \For{$i = 0$ to $I_2$}
              \State Pass current index through function: $o = I_1(i)$
              \State Add current output to running list: $O \gets O \cup o$
          \EndFor
          \State \Return $O$
          \end{algorithmic}
          \tagmcbegin{artifact}
          \vspace{2pt}
          \hrule
          \tagmcend{}
          \end{minipage}
          \end{flushleft}
        
        Like tables, figures, and equations, algorithms can be referenced in the text with the following: Algorithm ~\ref{alg:example} and Algorithm ~\ref{alg:exampleforaccessibility}.
